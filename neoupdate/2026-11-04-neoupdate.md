# November 4, 2026 Update Notice

Translated from the official [revised update notice](https://bns.plaync.com/board/neoupdate/view?articleId=6aea85e86cfe4756db5b9133),
posted 2026-11-04 01:10 KST. The known issues notice and the additional update notice for the same day are included
below as companion sections.

Greetings, Warriors.

We thank all our customers who love Blade & Soul NEO, and would like to announce the details of the update carried out on November 4.

## All Servers

### Events

**Event Started > Last Stand Twisted Labyrinth (after the 11/4 regular maintenance – before the 11/18 regular maintenance)**

- Added 10 items to the Dragon Express that can be exchanged for "Spiral Coins".
- Added 2 items to the Dragon Express that can be exchanged for "Variant Spiral Coins".
- Added "Spiral Coins" and "Variant Spiral Coins" to the daily/weekly mission rewards.

**Event Started > Temple Secret Artifact Chest (after the 11/4 regular maintenance – before the 11/25 regular maintenance)**

- Added 7 event transmutation recipes.

**Event Ended > The World's Best Martial Arts Tournament**

- The Arena Match individual ranking has ended, so matchmaking can no longer be conducted.
  - *Individual Arena Match sparring is still available.*

**Event Ended > 2 Fast?! Lightfoot Contest**

- Retired 1 event-related item.
- Removed the Lightfoot Contest-related quests.

**Event Ended > Double Mileage Event**

- Reverted the Mileage accumulated on Insignia Fusion to its pre-event value.
- Reverted the Mileage accumulated on Portrait Fusion to its pre-event value.

### PC Cafe

**PC Cafe > B&S Shop**

- Overhauled the list of items that can be purchased with PC Cafe Points.

### Items

**Item > Hongmoon's Blessing Recovery Potion**

- Fixed an issue where a Hongmoon's Blessing Recovery Potion could be used while a cooking item was in use at maximum Hongmoon's Blessing.
- Removed the reuse cooldown of the "Hongmoon's Blessing Recovery Potion", "Lesser Hongmoon's Blessing Recovery Potion" and "Hongmoon's Blessing Recovery Potion (Period)".

**Item > Aransu School Uniform**

- Jin > Fixed an issue where the arms were rendered in a different skin tone when a female character equipped the "Aransu School Uniform" costume.

**Item > Strange Crystal**

- Removed the acquisition-source section from the "Strange Crystal" item tooltip.

### Combat / Skills

**Class > Blade Master**

- Fixed an issue where "x2" was displayed in the area tooltip of the Mythical-grade "Heavenly Slasher" skill.
- Fixed an issue where "x2" was displayed in the area tooltip of the Mythical-grade "Thunder Drake Slash" skill.
- Fixed an issue where Skill Enhancement Points could not be applied after transferring the "Five Point Strike: Draw Stance" skill.
- Fixed an issue where, without transferring the "Celestial Thunder" skill, using the Superior-grade "Dragontongue" skill under the "Black Dragon" buff stacked the "Talus Dungeon" effect.

**Class > Kung Fu Fighter**

- Fixed an issue where "x2" was displayed in the area tooltip of the Mythical-grade "Tiger Strike" skill.

**Class > Force Master**

- Fixed an issue where "x2" was displayed in the area tooltip of the Mythical-grade "Blazing Beam" skill.

**Class > Summoner**

- Fixed an issue where "x2" was displayed in the area tooltip of the Mythical-grade "Super Sunflower" skill.

**Class > Flame Warden**

- Fixed an issue where "x2" was displayed in the area tooltip of the Mythical-grade "Raging Dragon Slash" skill.

### Dungeons

**Dawncrest > Temple of Eluvium**

- Changed the boss NPC Great Thrall's "Hellfire" debuff so that it is applied in line with the visual presentation.

**Dawncrest > Ashewind Cave**

- Fixed an issue where portals occasionally could not be used during the fight with the boss NPC Ghost Yomio.
- Fixed an issue where, in the boss NPC Ghost Yomio's special pattern, the second orb disappeared if the first orb was not blocked.

### Regions

**Region > Clan Headquarters**

- Lyn > Fixed an issue where using the Tailor Shop in the Clan Hunting Grounds made you fall through the floor.

### Systems

**System > Challenge Reward**

- Improved the dungeon Challenge Reward icon so that you can check whether you can obtain the dungeon reward when entering a dungeon.
- Improved the dungeon Challenge Reward icon tooltip so that, if the Challenge Reward cannot be obtained, the reason is displayed.
- Added a tooltip to the dungeon tooltip showing whether the Challenge Reward conditions are met.
- Improved this so that a notification message is displayed on entering a dungeon if the dungeon Challenge Reward cannot be obtained.
- Improved this so that a notification message about whether the Challenge Reward can be obtained is displayed when a fight with a boss NPC begins.

**System > Chests**

- Improved this so that, when you hold multiple selection chests, you can select and open several items at once.

**System > Inventory**

- Added a function at the bottom of the Inventory to open all probability chests and fixed-reward chests.

**System > Revival**

- Changed this so that, if all party members die during a boss NPC fight in a dungeon while a Familiar remains, the Summoner class character can be revived.
  - *After the Summoner class character is revived, the other party members can also be revived.*

### Interface

**Interface > Mileage**

- Fixed an issue where the percentage value of the Portrait and Insignia Fusion Mileage was displayed differently from the actual value.

**Interface > Dragon Pulse**

- In some dungeons, when you approach the boss's location and a retry Dragon Pulse is created, a Dragon Pulse activation notification message is now displayed.

**Interface > Illusion Soul Shield**

- Added a button to change whether the Illusion Soul Shield is displayed.

**Interface > Item Buffs**

- Added an icon panel for checking the duration of item buffs such as "Satisfied" and "Serendipity".
  - *If buttons or windows overlap, you can adjust or reset their positions with [Shift + F1].*

**Interface > Rewards**

- Fixed an issue where the light effect was occasionally not displayed on drop rewards.

**Interface > B&S Shop**

- Enlarged the B&S Shop window.

### Client

**Client > PC Cafe Exclusive Benefits**

- Fixed an issue where the PC Cafe-exclusive costume disappeared when you returned after using an Arena Match or the Lightfoot Contest while wearing it.

## Neo Servers (Jin, Lyn)

### Events

**Event Ended > Queen's Treasure Chest**

- Removed 4 event exchange items from the Dragon Express.

## Specialization Servers (Gold)

### Events

**Event > 2nd Anniversary Special Lucky Chest**

- Added 7 event-related items to the Dragon Express.
- Added 2 event transmutation recipes.

### Items

**Item > The More Golden Ticket**

- Fixed an issue where the probability was applied as 0% when trying to evolve a Bound Winterbane Weapon, Bound White Light Weapon, Bound Winterbane Accessory, Bound White Light Accessory, +0 Gold Line Weapon, +0 Bound Gold Line Weapon, +0 Gold Line Accessory or +0 Bound Gold Line Accessory using The More Golden Ticket.

Thank you.
