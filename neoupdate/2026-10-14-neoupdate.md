# October 14, 2026 Update Notice

Translated from the official [October 14 update notice](https://bns.plaync.com/board/neoupdate/view?articleId=6aced66828c7452635072b5a),
posted 2026-10-14 02:00 KST.

Greetings, Warriors.

We thank all our customers who love Blade & Soul NEO, and would like to
announce the details of the update carried out on October 14.

## All Servers

### Events

**Event Ended > Soaring Spirit Shop**

- Retired 2 event-related items.
- Removed the event-related purchase items from the Dragon Express.
- Changed the "Equipment Enhancement Effect Reset Ticket" so that it can no longer be used for equipment effect resets.

### Dungeons

**Dawncrest Isle > Ashewind Cave**

- Adjusted the Challenge reward conditions of the dungeon.
- Fixed an issue where the boss NPC M-ao's "Phantom Smash" and "Awakened Phantom Smash" could be resisted.

**Dawncrest Isle > Moonrise Tourney Hall**

- Changed the boss NPC M-ao's special-pattern "Crescent Slash" to "Vertical Slash".
- Changed the boss NPC M-ao so that it no longer uses "Backstep" after you successfully counter its "Taunting Lunar Smash".

**Mushin's Hall > Darkstorm Training Ground**

- Lowered the value of the healing-reduction effect.
- Lowered the attack power of the Darkstorm Training Ground NPCs.

### Regions

**Dawncrest Isle > Field Boss**

- Changed the Dawncrest Isle field bosses so that they appear at fixed locations.

### Systems

**System > Character Switching**

- Made it possible to switch characters in-game.
- Clicking the Character Select button in the Game Menu now opens the character selection window.
- The character selection window only lists characters on the same server as the character you are currently logged in with.

**System > Dragon Pillar**

- Added 3 Dawncrest Isle field boss spawn areas to the Dragon Pillar list.

### Interface

**Interface > Level Range Rewards**

- Fixed an issue where the Level Range Rewards were not displayed on first login.

## Neo Servers (Jin, Lyn)

### Events

**Event Started > Ballroom Outfit Chest (after the 10/14 regular maintenance – before the 10/28 regular maintenance)**

- Added 5 items to the Dragon Express that can be exchanged for "Mask Coins".

**Event > Ebondrake Treasure Chest**

- Added 4 event transmutation recipes.

**Event Ended > Comeback Style Outfit Chest**

- Retired 1 event-related item.
- Removed the event transmutation recipe.

Thank you.
