# September 2, 2026 Update Notice

Translated from the official [September 2 update notice](https://bns.plaync.com/board/neoupdate/view?articleId=6a9759dba279104f7d9d5a06),
posted 2026-09-02 02:10 KST. Distinct from
[2026-09-02-neonews.md](2026-09-02-neonews.md), which translates a
same-day `neonews` board post (shop/event roundup) rather than these official
patch notes.

Greetings, Warriors.

We thank all our customers who love Blade & Soul NEO, and would like to
announce the details of the update carried out on September 2.

## Server-wide

### Events

**Event Started — Soaring Spirit Shop** (after 9/2 maint. – before 10/7 maint.)
- Added event-related items to the Dragon Trader's sell list.
- Added "Equipment Enhancement Effect Reset Ticket" to the offering list used
  for equipment-effect resets on Uncheong/Winterbane/White Light-tier gear.
- Added "Equipment Enhancement Effect Reset Ticket" to the offering list used
  for equipment-effect resets on Desert/Moonwater/Virtuous/Sacred-tier
  Soul/Mystic Badges.

**Event Ended — Riotous Passion Sky Park Event**
- Removed the event dungeon located in Bright Night Garden.
- Removed the event-related quest.
- Removed "Gold Coin Chest" from the exchange list sold by NPC Dragon Trader
  "Eunha."

### Items

**Items > Legendary Mushin's Soul Core**
- Fixed an issue where the "Burning Soul Core Equipment Effect Change Ticket"
  couldn't be used on +1–+5 Legendary Mushin's Soul Cores.

**Items > Soul Badge**
- Added a note about costume disassembly to the Bloodshade Soul Badge's
  obtain-source info.

**Items > Merchants**
- Removed Repair Tool from the Dragon Trader general-goods merchant's sell
  list.
- Added Repair Tool to the "Cheolmubang" (철무방, lit. "Iron Martial Hall")
  weapon merchant's sell list.
  
**Items > Enhancement**
- Added an enhancement recipe for Bound Gold Line Weapons using "Hangamaeng's
  Gold Line Weapon Enhancement Stone (~+3)."
  
### Combat / Martial Arts

**Class — Destroyer**
- Fixed an issue where "Cleave: Speed Increase (Superior, Heroic)" wasn't
  granting its "restore 20 Focus on Critical Hit" effect.
- Fixed an issue where Fury stacks would build up when the
  Desert/Moonwater/Virtuous-tier Mystic Badge's "Emberstomp" effect applied.
  - Fixed an issue where, with "Celestial Thunder" (천뇌옥) inherited, the
  Desert/Moonwater/Virtuous-tier Mystic Badge's "Mighty Cleave" effect would
  trigger Celestial Thunder without a Fury charge.

**Class — Warlock**
- Fixed an issue where Fury stacks would build up when the
  Desert/Moonwater/Virtuous-tier Mystic Badge's cooldown-reduction effects on
  "Wingstorm" and "Hex Storm" applied.
  
  
**Class — Flame Warden**
- Fixed the Skill Guide UI showing the acquisition level for "Sear Step" as
  level 18.

### Dungeons

**Mushin's Hall > Darkstorm Training Ground**
- Added a progress indicator to the dungeon's in-progress status and results
  window.

### Region

**Dawncrest Isle > Bright Night Garden**
- Added a Wooden Training Dummy NPC (목각인형, lit. "wooden puppet") to Bright
  Night Garden.

### Quests

**Quest > Side Story**
- Made some cutscenes in the "Crack in the Martial World" quest skippable.

### System

**System > Key Bindings**
- Added a "Clear Hotkey" button.

**System > Skill Macro**
- Fixed so you can no longer assign a macro hotkey that's already in use.

**System > Character Creation**
- Fixed so Boost Server guidance no longer appears during Neo/Specialization
  server character creation once you've used both Server Transfer attempts.

**System > Gallery**
- Fixed a delay that occurred when registering Portraits back-to-back in the
  Gallery's Collection tab.

**System > Character**
- Changed so character nameplates stay visible even when the frame rate drops
  below a certain threshold.

**System > Hongmoon Blessing**
- Fixed an issue where you could receive the bonus reward for Hongmoon
  Blessing's Accelerated Mode even without meeting its requirements.
- Fixed an issue where the Hongmoon Blessing icon displayed in its "has
  Blessing" color even at 0 Blessing.

**System > Portrait**
- Changed the Legendary Portrait mileage reward to the "Legendary Portrait
  Selection Box."

### Interface

**Interface > Mission**
- Improved so the Daily Mission / Weekly Mission UI hides itself once there
  are no more tasks left to progress.

**Interface > Skill Book**
- Changed the sort order of Skill Book succession slots.
- Improved the Skill Book tooltip to show the list of skills it can be changed
  into.

**Interface > Server Transfer**
- Changed so a specific server is no longer auto-selected the first time you
  open the Server Transfer application window.
- Changed so the "Server Transfer" button stays disabled until you select a
  destination server.
- Changed so, after applying, the "Cancel Transfer" icon at the bottom of the
  HUD shows a "Transfer pending to selected server" message.
