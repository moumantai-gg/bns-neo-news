# September 23, 2026 Update Notice

Translated from the official [September 23 update notice](https://bns.plaync.com/board/neoupdate/view?articleId=6ab326e86b722c561dc6a737),
posted 2026-09-23 01:55 KST, with the same day's
[known issues notice](https://bns.plaync.com/board/neoupdate/view?articleId=6ab332056b722c561dc6a75e),
posted 2026-09-23 03:16 KST, appended as a companion section.

Greetings, Warriors.

We thank all our customers who love Blade & Soul NEO, and would like to
announce the details of the update carried out on September 23.

## New Heroic Dungeon: Ebondrake Execution Grounds

**Dungeon > Dawncrest Isle > Ebondrake Execution Grounds**

- Added the new Heroic dungeon "Ebondrake Execution Grounds" to the Bright
  Night Garden region.
- ※ The Ebondrake Execution Grounds can be entered with characters level 60
  or above.

## Server-wide

### Events

- **"The Sky Is High, and the Horses Grow Fat!":** Fixed an issue where
  defeating a field boss in the Silverfrost Mountains region would
  occasionally fail to grant the "Mystical Maple Leaf" needed to complete the
  quest.
- **Burning Treasure Chest:**
  - Deprecated the event-related items.
  - Removed the event purchase items from the Dragon Express.
  - Removed the event transmute recipes.
  - Fixed an issue where the "Burning Sagewood Soul Shield Equipment Effect
    Change Ticket" could not be used.
  - Corrected the "Burning Sagewood Soul Shield Equipment Effect Change
    Ticket" usage deadline to before the 9/30 (Wed) regular maintenance.
- **Event Ended — Lord of the Damned Field Summon Event:**
  - Deprecated 6 event items.
  - Made the event EXP charms unusable.
  - Removed the event items from the shop of NPC Dragon Trader "Eunbi,"
    located in Zaiwei and Bright Night Garden.
  - Changed the "Fervent White Light Equipment Effect Reset Ticket" and
    "Fervent Windshock Soul Shield Effect Reset Ticket" so they can no longer
    be used for equipment effect resets.
- **Event Ended — Martial World Journey Costume Box:**
  - Deprecated 1 event item.
  - Removed the items exchangeable for "Time Token" from the Dragon Express.

### Items

- **Soul Badge:** Removed the exchange information from the tooltips of
  "Desert Soul Badge Exchange Ticket," "Moonwater Soul Badge Exchange Ticket,"
  "Desert Soul Badge Fragment," and "Moonwater Soul Badge Fragment."
- **Accessories:** Added "Bloodshade Necklace" and "Bloodshade Bracelet."
- **Portraits:** Added 1 new Portrait. Added 3 new Special Portraits.

### Dungeons

**Silverfrost Mountains > Dungeons**

- Increased the drop rates of "Winterbane Jade" and "Winterbane Steel" in 5
  Silverfrost Mountains dungeons.

| Category | Target Dungeons |
|---|---|
| Superior Dungeons | Chuanka Frost Cavern |
| | Ebondrake Hideout |
| | Talus Dungeon |
| Heroic Dungeons | Sogun's Lament: Gardens |
| | Sundered Nexus: Upper Floor |

**Silverfrost Mountains > Ebondrake Hall**

- Defeating boss NPC "Lord of the Damned" now also drops "Gold Line Steel,"
  and the "Gold Line Jade" rate has been adjusted.
- Slightly increased the drop rate of "Ascension Stone" from defeating boss
  NPC "Lord of the Damned."
- Removed "Superior Skill Book Fragment" from the rewards obtainable by
  defeating boss NPC "Lord of the Damned."

**Dawncrest Isle > Phantasmic Beast Arena**

- Fixed an issue where a cinematic would play when warping to the Phantasmic
  Beast Arena dungeon after clearing the Room of Sundering dungeon.

**Dawncrest Isle > Frozen Abandoned Mine**

- Changed the "Groggy" status effect used by boss NPC "Barakal" in its special
  pattern so that it can no longer be resisted.

### System

- **World Boss Ranking:** Fixed an issue where the World Boss contribution
  rank was displayed differently from the actual rank.
- **Retry:** Improved so that the "Retry" function can be used after clearing
  a dungeon while in a party.
- **Probability Details:** Fixed an issue where, in the Probability Details
  window for chests opened with a key, the category name and the item name
  overlapped when a category was collapsed.
- **Exploration Journal:** Fixed an issue where Story > "Precious Children"
  could not be completed.
- **Equipment:**
  - Improved so that the Supreme Force increase or decrease is shown in
    equipment effects.
  - Improved so that an Essence Transfer can be performed while the equipment
    is still worn.
- **Dragon Pillar:** Improved so that party size information is shown on
  Dragon Pillar recruitment posts.
- **Gallery:**
  - Added 1 new Bond.
  - Added 1 new Collection entry.
  - Fixed an issue where a registration system message was displayed when
    using Register All with no fusible Portraits available.

### Interface

**HUD**

- Fixed an issue where the text at the bottom of the Challenge Reward HUD was
  labeled "Hongmoon Blessing."
- Fixed an issue where the EXP segment display did not scale proportionally
  depending on resolution.
- Fixed an issue where the Soul Pass was shown as active after the previous
  season's Soul Pass had ended.

### Known Issues

**System > Exploration Journal**

- The Exploration Journal entry "[Dawncrest] Defeat Kumakage" displays the
  icon with the image of the Lord of the Damned.
