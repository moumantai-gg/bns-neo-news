# August 26, 2026 Update Notice

Translated from the official [August 26 update notice](https://bns.plaync.com/board/neoupdate/view?articleId=6a8e2938bcc863198922329a),
posted 2026-08-26 05:20 KST, plus a same-day companion notice appended at the bottom: the
[known issues notice](https://bns.plaync.com/board/neoupdate/view?articleId=6a8e86bcd97eae18cc40dc75).

Greetings, Warriors.

We thank all our customers who love Blade & Soul NEO, and would like to announce
the details of the update carried out on August 26.

## Server-wide

### Events

**Event Started — Portrait Synthesis Cost Discount** (after 8/26 maint. – before 9/9 maint.)
- Reduced Refined- and Superior-tier Portrait Synthesis costs during the event period.

**Event > Last Stand Blackram Supply Chain**
- Fixed an issue where a party member who entered the dungeon late during the fight
  against boss NPC "Poharan" couldn't proceed to the next zone.
- Fixed an issue where the retry Dragon Vein wasn't spawning.

### Items

**Items > Merchants**
- Added "Silverfrost Mountains Easy Treasure Chest" and "Moonwater Plains Easy
  Treasure Chest" to the Dragon Trader's exchange-merchant sell list.

**Items > Soul Badge**
- Changed the Dawncrest Soul Badge succession material to "Dawncrest Soul Badge
  Fragment."

**Items > Skill Book Box**
- Fixed an issue where the Radiant Bound Skill Book Non-Branch Selection Box
  contained skill books that couldn't be inherited.

### Combat / Martial Arts

**Class — Force Master**
- Added descriptions for "Yeomok" (염옥, lit. "flame prison") and "Bingok" (빙옥,
  lit. "ice prison") to the Skill Guide.

**Class — Flame Warden**
- Fixed an issue where other players' screens would shake when a Flame Warden used
  certain skills.

### Dungeons

**Mushin's Hall > Darkstorm Training Ground**
- Fixed an issue where the combat EXP bonus effect wasn't applying in Darkstorm
  Training Ground.

**Mushin's Hall > Mushin's Tower**
- Floors 5–6: killing NPCs there no longer consumes Hongmoon Blessing (now 0), and
  only normal material rewards can be obtained.
- Changed Hongmoon Blessing consumption to 12 for killing the floor-7 NPC
  "Junghado."
- Changed the kill reward for floor-7 NPC "Junghado."

**Mushin's Hall > Silverfrost Trials**
- Floors 1–2: killing NPCs there no longer consumes Hongmoon Blessing (now 0), and
  only normal material rewards can be obtained.
- Changed Hongmoon Blessing consumption to 12 for killing the floor-3 NPC
  "Raging Yeti Manifestation."
- Changed the kill reward for floor-3 NPC "Raging Yeti Manifestation."

**Silverfrost Mountains > Ebondrake Hall**
- Fixed an issue where Jaha Demon God's Demonic Energy Projectile would
  occasionally become invisible.
- Changed the basic attack used by Demonized Zealots.
- Fixed an issue where Yomaaeran's Veil Attack was displayed in a color indicating
  it could be resisted (when it couldn't).

### Quests

**Quest > Daily Quest**
- Removed the daily quest related to "Mushin's Tower."
- Added the "Final Training" quest.

**Quest > Side Quest**
- Improved the "Mercenary Captain's Headache" quest so NPC "Mak Yori's" location is
  easier to find.

**Quest > Side Story**
- Shortened the spawn-wait time for the Gwidosi Brazier during "Crack in the
  Martial World Ch. 1."

### System

**System > Guidebook**
- Added a Help tab to the Guidebook.
- Added loading-tip images to the Help tab.

**System > Welcome Warrior**
- Improved so the Welcome Warrior icon displays when typing in chat, in the
  party-applicant list, and next to names in the party list.

**System > Darkstorm Training Ground**
- Added a Dragon Pillar teleport effect when entering Darkstorm Training Ground.
- Made the Darkstorm Training Ground results cutscene skippable via ESC.

**System > Path of Growth**
- Completing all of Path of Growth now opens the Boost Mission window.
  *(If there are no Boost Missions, the Guidebook window opens instead.)*

**System > Resurrection**
- Fixed an issue where characters auto-revived from exhaustion/death after a
  dungeon boss kill would occasionally fail to receive drop rewards.

**System > Clan**
- Fixed an issue where rank-permission edits made in Clan Management would reset
  if you reopened the Clan window.
- Added a "Find Clan" feature that shows a list of clans when you aren't in one.

**System > Dungeon Tooltip**
- Added a Dragon Pillar button to the tooltip shown when clicking a dungeon-name
  link in the Mushin's Hall region.
  *(Using it takes you to Mushin's Hall.)*

### Interface

**Interface > Skill Book**
- Added a skill-hotkey icon to skill books, including equipped skill books shown
  in the Skill Manual window.

**Interface > Gallery**
- Renamed the filter option "Evolution" to "Event."

**Interface > Skill Manual**
- Improved the visibility of the variant-skill selection button in the skill
  selection window.

**Interface > World Map**
- Fixed an issue where, on Mushin's Hall floor 2, checking the
  parent map would show your position in an odd location.

**Interface > Quest**
- Fixed an issue where some quests weren't displaying as "appropriate level"
  regardless of the level gap with the character, as intended.

**Interface > Server Select**
- Fixed an issue where, on first login, the server name had to be clicked twice
  before it registered as selected.

## Neo Servers (Jin, Lyn)

**Soul Pass**
- **NEO Soul Pass ended:** Deprecated 5 items related to the previous season;
  removed items exchangeable with "Soul Pass Red Serpent Coin" from Dragon
  Express; removed the event enhancement recipe using "Gold Line Accessory
  Enhancement Stone (\~+1) (Account-Only)"; "Sagewood Soul Shield Equipment Effect
  Change Ticket" can no longer be used for equipment-effect resets.

**Events**
- **"Burning Treasure Chest":** Added 3 event transmute recipes.
- **Event Ended — "Ashen Treasure Chest":** Removed items exchangeable with "Ashen
  Fragment" from Dragon Express; removed 5 event transmute recipes; removed the
  event enhancement recipes using "Ashen Gold Line Weapon Enhancement Stone (\~+5)"
  and "Ashen Gold Line Accessory Enhancement Stone (\~+5)."
- **Event Ended — "Red Dragon Costume Box":** Removed items exchangeable with
  "Dragon Coin" from Dragon Express.

**Items**
- Merchants: Changed the exchange-level requirement for the voucher in Sillyong
  Gongsang's exchange-merchant list to 76.

## Specialization Server

**Soul Pass**
- **Specialization Soul Pass ended:** Removed items exchangeable with "Soul Pass
  Red Serpent Coin" from Dragon Express; removed the event enhancement recipe
  using "Gold Line Accessory Enhancement Stone (\~+1) (Account-Only)"; "Sagewood
  Soul Shield Equipment Effect Change Ticket" can no longer be used for
  equipment-effect resets.

**Events**
- **"Martial World Lucky Box":** Added 2 items exchangeable with "Martial World
  Energy" to Dragon Express.

## Boost Server

**Quests**
- Boost Mission: Changed the completion requirements for some growth missions.

**Interface**
- Boost Mission: Added a highlight effect on the Boost Mission tied to the next
  dungeon in progress once Path of Growth is completed.

**System**
- Server Transfer: Fixed an issue where canceling a Server Transfer application
  would occasionally make it look like your remaining application count had been
  deducted.

Thank you.
