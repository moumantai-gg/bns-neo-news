# November 11, 2026 Update Notice

Translated from the official [revised update notice](https://bns.plaync.com/board/neoupdate/view?articleId=6af3a899577e8c01355e04b1),
posted 2026-11-11 01:10 KST.

Greetings, Warriors.

We thank all our customers who love Blade & Soul NEO, and would like to announce the details of the update carried out on November 11.

## All Servers

### Events

**Event Started > Value Soul Core Support Chest (after the 11/11 regular maintenance – before the 11/25 regular maintenance)**

- Added 6 event-related items.
- Added the "Mushin's Soul Core Equipment Effect Change Ticket" to the materials used as the offering for resetting the equipment effects of the "Mushin's Soul Core".

**Event Started > Putting a Heart into the Ashen Wind (after the 11/11 regular maintenance – before the 11/18 regular maintenance)**

- Added 1 event-related item.
- Placed Dragonblood Heart charging objects in the Ashewind Cave dungeon.
  - *You can charge Dragonblood Hearts with the event item "Hongjae's Gratitude".*
- Added "Hongjae's Gratitude" to the drop rewards of 2 dungeons in the Dawncrest region.

| Category | Target dungeons |
|---|---|
| Heroic dungeons | Garden of Reflection |
| | Moonrise Tourney Hall |

**Event Ended > 2nd Anniversary Special Brother Hajoon's Tome**

- Retired the "Brother Hajoon's Energy" item.
- Removed 10 event exchange items from the Dragon Express.

**Event Ended > 2 Fast?! Windwalk Race**

- Retired the "2nd Anniversary Windwalk Race Coin" item.
- Removed the Dragon Trader Eunyu NPC.

**Event Ended > NEO Arena Tournament**

- Retired 4 event-related items.
- Removed the event shop "Arena Tournament" tab from the Nameless Agent NPCs in all regions.

### Items

**Item > Succession**

- Added a succession recipe that lets you promote +5 "Legendary Bound Mushin's Soul Core" equipment to "Brilliant Bound Mushin's Soul Core" equipment.

### Combat / Skills

**Class > Common**

- Fixed an issue where some skill chaining became impossible after transferring the "Celestial Thunder" skill.

**Class > Assassin**

- Fixed an issue where the additional damage effects at 18 and 48 Skill Grandmaster points of the "Poison Breath: Critical Bonus" skill were not applied.

**Class > Force Master**

- Fixed an issue where Skill Grandmaster effects were displayed on the "Frost Armor" and "Ice Burst" skills.

### Dungeons

**Dawncrest > Moonrise Tourney Hall**

- Removed the skill the boss NPC M-ao uses when its special pattern fails.
- Lowered the "Darkness Explosion" damage of the boss NPC M-ao.
- Removed the "Shadow Fury" effect of the boss NPC M-ao.
- Changed it so that damage is applied each time the boss NPC M-ao has a "Darkness Vulnerability" effect created.
  - *For Daze, it still takes 3 stacks to apply, as before.*

**Dawncrest > Temple of Eluvium**

- Fixed an issue where the boss NPCs Flaming Asura and Frozen Asura entered Berserk Rage even though Berserk Rage time remained.
- Changed the Berserk Rage times of Ken, Gen, Fengsho, Blood Thrall, Magma Augerite, Frozen Augerite, Doom, Ikari and Cleave.

### Regions

**Clan Headquarters**

- Removed the Berserk Rage time of the Raven King summoned with the Harbinger's Charm.

### Quests

**Quest > Side Story**

- Fixed an issue where the names of the NPC Namgun Sunjay and the Realmwalker Amulet moved during "Dawncrest Chapter 14: Realmwalker Seal Site".

### Systems

**System > Camera**

- Fixed an issue where the camera view shifted if you were hit by an aerial attack after being caught by a Blade Dancer's "Phantom Grip" or a Destroyer's "Grab".

**System > Party Finder**

- Improved it so that, when the party reaches its maximum size during party promotion, the promotion ends after the last party member's information is displayed.

**System > Antique Auction**

- Fixed an issue where, during an Antique Auction, an amount you had typed in as your bid was reset if another player placed a bid.

**System > Character Info**

- Fixed an issue where some skills in "Skill Usage Status" in Character Info were displayed differently from the skills actually used.

**System > Fuse**

- Added a function that, when an item in the Fuse window has reached 100% Mileage, displays the Mileage reward and lets you receive it.

### Interface

**Interface > Inventory**

- Fixed an issue where the Open All Chests icon was not disabled when it could not be used.

### Known Issues

**System > Character Info**

- An unusable button is displayed in the "Main Transferred Skills" position of the Character Info window.
- When you check another character's information on the same account in the Character Info window, the "Supreme Force" text is displayed.

## Neo Servers (Jin, Lyn)

### Events

**Event Ended > Queen's Treasure Chest**

- Retired 25 event-related items.
- Removed 20 event exchange items from the Dragon Express.
- Removed the event enhancement recipes that use the "Gold Line Equipment Fixed Enhancement Stone", "Bloodshade Accessory Fixed Enhancement Stone" and "Bracelet Enhancement Stone".
- Changed the "Hive Queen Equipment Effect Change Ticket", "Hive Queen Mystic Badge Enchantment Effect Change Ticket", "Hive Queen Soul Core Equipment Effect Change Ticket" and "Hive Queen Sagewood Soul Shield Equipment Effect Change Ticket" so that they can no longer be used to reset equipment effects.

### Items

**Item > Costume**

- Added 6 new costumes.

**Item > Illusion Weapon**

- Added 1 new Illusion Weapon.

Thank you.
