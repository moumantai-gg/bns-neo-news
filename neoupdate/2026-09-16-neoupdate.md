# September 16, 2026 Update Notice

Translated from the official [September 16 update notice](https://bns.plaync.com/board/neoupdate/view?articleId=6aa9ea10fa34c1011d62776a),
posted 2026-09-16 02:10 KST.

Greetings, Warriors.

We thank all our customers who love Blade & Soul NEO, and would like to
announce the details of the update carried out on September 16.

## Server-wide

### Events

- **Event Started — "The Sky Is High, and the Horses Grow Fat!"** (after
  9/16 maint. – before 10/7 maint.): The event daily quest "A Mystical Maple
  Outing" can now be obtained via Letter.
  - Defeating a field boss in Silverfrost Mountains or Dawncrest Isle
    completes the event quest.
  - Completing the event quest grants the event item Maple Leaf.
  - Defeating a dungeon boss in Silverfrost Mountains or Dawncrest Isle
    grants the event item Songpyeon.
  - Added the event item Maple Leaf to the Weekly Challenge 3-completions
    reward.
  - Songpyeon and Maple Leaf obtained through event participation can be
    exchanged for rewards via NPC Dragon Trader "Eunyu," located at the
    Gangnyusi Merchants' Guild, Bright Night Garden, and Mushin's Hall.
- **Event Ended — Jahamasin Field Summon Event:** Removed Jahamasin's
  Special Loot from the Suspicious Ritual drop rewards.
- **Event Ended — Naryuguk's Treasure Hunt:** Removed the Treasure Hunt Key
  Pouch from dungeon drop rewards. Deprecated 11 event items. Removed the
  "Naryuguk's Treasure Hunt" tab from event merchant NPC Dragon Trader
  "Eunbi."
- **Event Ended — Burning Treasure Chest:** Removed the Burning Treasure
  Chest from the Dragon Express.
- **Event Ended — Fervent Welcome Warrior:** Removed all Welcome Warrior
  benefits.
- **Event Ended — Grow into a Fervent Clan!:** Reverted the discount rates
  on Clan founding cost, rank growth cost, and enhancement cost to their
  pre-event values.
- **Event Ended — Last Stand Blackram Supply Chain:** Deprecated 3 event
  items. Removed event merchant NPC Dragon Trader "Eunha." Removed 2 event
  quests.

### Items

- **Weapon:** Changed the icon and appearance of some Spear weapons.
- **Illusion Weapon:** Changed the icon and appearance of some Illusion
  Spears.

### Combat / Martial Arts

**Common**
- Improved it so the Celestial Thunder skill's noeok charge count now
  displays on its buff icon.

**Summoner**
- Fixed an issue where the "Cheer Up! (Superior)" skill couldn't be used
  while moving.

**Flame Warden**
- Fixed it so that, while using Yeomwangjin, Yeomnyonggeom, Gwangnyongcham,
  or Gwangnyonggangcheon, you can now link into Strafe, Sear Step, or
  Backstep.

### Dungeons

**Mushin's Hall > Darkstorm Training Ground**
- Fixed it so party invites and Support are now possible inside Darkstorm
  Training Ground.

### Quests

**Daily Missions**
- Changed the "Hongmoon Blessing Potion (Timed)" reward for completing 3
  Daily Missions to the new season's version.

### System

**Settings**
- Fixed it so setting Graphics Detail Settings > Overall Setting to Level 2
  now applies the Light Bloom Effect.

**Skill Book**
- Improved it so that equipping a Skill Book for the first time now
  displays a Skill Move selection window.

**Hongmoon Blessing**
- Added a warning — shown via the Notification Center, headline message,
  and system message — when entering a dungeon or starting combat with a
  boss NPC while Hongmoon Blessing is at 0.

**Challenge Box**
- Improved the Challenge Box acquisition condition for dungeons: the party
  can now obtain the Challenge Box if at least one party member's personal
  highest Supreme Force is within the recommended Supreme Force range.
- Added a daily limit on the number of times a Challenge Box can be
  obtained.

**Compendium**
- Added an "All" tab to the filter.

**Wardrobe**
- Added an "All" tab to the filter.

**Achievement**
- Added 2 new achievements related to the Ruler of the Land collaboration.
- Added Titles to some achievement rewards.

**Portrait**
- Changed the completion reward for the Bonds Conflict Between the
  Righteous and the Evil, The Two Supreme Masters, The Five Great Warriors,
  and Master of the Eight Great Treasures.

### Interface

**Character Info**
- Improved it so the Seal tab now displays your equipped Seal.

**My Info**
- Fixed an issue where the Portrait Book tooltip displayed Critical Chance
  and Critical Damage Rate values 10x too high.

**Inventory**
- Improved it so items registered as Favorites in Inventory now display
  their cooldown time.

**Skill Guide**
- Changed the magnifying-glass button in the Guide Preview.
- Added a "Use Guide Preview" button at the bottom of the Skill Guide.

**Skill**
- Improved the Skill context slot to display cooldown times up to a maximum
  of 99 seconds.

**HUD**
- Fixed HUD icon tooltips to display above their icon.

**Loading**
- Added 3 new loading-screen images.

**Portrait Book**
- Fixed an issue where the Bonds tab filter's default value displayed as
  "All/1."

## Known Issues

**Detailed Probability Info**
- There is an issue where, in the Detailed Probability Info window for
  boxes opened using a key, collapsing a category causes the category name
  and item names to overlap.
