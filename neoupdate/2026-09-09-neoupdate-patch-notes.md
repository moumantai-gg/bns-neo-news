# September 9, 2026 Update Notice

Translated from the official [September 9 update notice](https://bns.plaync.com/board/neoupdate/view?articleId=6aa0b1e8a279104f7d9d5b0e),
posted 2026-09-09 05:40 KST.

Greetings, Daehyeop.

We thank all our customers who love Blade & Soul NEO, and would like to
announce the details of the update carried out on September 9.

## Server-wide

### Events

- **Burning Treasure Chest:** Added 2 new event transmute recipes.
- **Last Stand Blackram Supply Chain:** Lowered named NPC Mak Sobo's and boss
  NPC Poharan's HP and regeneration.
- **Event Ended — "Riotous Passion Sky Park" Event:** Deprecated 8 event
  items. Removed 3 event exchange items sold by Dragon Trader NPC "Eunha."
- **Event Ended — Portrait Synthesis Cost Discount:** The event period ended,
  so Refined- and Superior-grade Portrait synthesis costs reverted to their
  original costs.

### Items

- **Soul Badge / Mystic Badge:** Added an enhancement recipe using the
  "Soul/Mystic Badge Transformation Stone Crystal" for Bound Soul Badges and
  Bound Mystic Badges of the Sacred and Dawncrest generations.

### Combat / Martial Arts

**Kung Fu Master**
- Fixed successful Counters not applying their resistance effect.

**Assassin**
- Fixed an issue where, after selecting "Lightning Stab (Heroic, Legendary)"
  and using the auto skill-point distribution feature, 10 skill points were
  left unspent.

### Dungeons

- **Mushin's Hall > Darkstorm Training Ground:** Changed NPC "Assault Squad"
  to go berserk once enough time passes or enough of them gather.
- **Dawncrest Isle > Frozen Abandoned Mine:** Fixed boss NPC "Barakal" to use
  Gaze twice during its first special pattern. Added a buff icon for the
  "Frost Spread" status. Lowered the damage dealt on successfully completing
  the special pattern.
- **Dawncrest Isle > Red Sand Ruins:** Lowered in-dungeon NPC stats. Lowered
  the dungeon's Challenge reward requirement.
- **Dawncrest Isle > Ashewind Cave:** Lowered in-dungeon NPC stats. Lowered
  the dungeon's Challenge reward requirement.

- **Silverfrost Mountains > Ebondrake Hall:** Fixed an issue where boss NPC
  "Jaha Demon God"'s "Jillyong-unjunghaeng" skill wasn't hitting party
  members near the target.

### Region

- **Dawncrest Isle > Bright Night Garden:** Added Dragon Trader exchange
  merchant NPC "Seoreun." Fixed a visual issue where a Dragon Pillar was
  rendering in mid-air over the island.

### Quests

- **Daily Quests:** Lowered the maximum Supreme Force cap for the Frozen
  Abandoned Mine and Garden of Meditation daily quests. Lowered the minimum
  Supreme Force requirement for the Ashewind Cave and Red Sand Ruins daily
  quests.

### System

- **Skill Book:** Fixed an issue where inheriting a different-grade skill
  while a skill was locked would unlock it. Fixed an issue where entering
  combat while switching Skill Presets made skills unusable.
- **Achievement:** Changed the completion condition for the "Big Spender of
  Equipment Crafting" achievement.
- **Dungeon Entry:** In some dungeons, other party members can no longer
  enter the dungeon while a boss NPC fight is already in progress.
- **Welcome Daehyeop:** Party members can no longer receive Welcome Daehyeop
  benefit rewards if the benefiting character in the party has no Hongmoon
  Blessing left to consume.

### Interface

- **News:** Added a "News" button to the bottom HUD; removed the News menu
  from the Game Menu.
- **Welcome Daehyeop:** Fixed the party member list's title icon to update
  based on whether the Welcome Daehyeop title is set to display.
- **Seal:** Fixed the Seal Combination window to display all 10 combination
  slots.
- **Character Info:** Fixed the Bound icon rendering incorrectly
  (inconsistent with the actual Skill Book's own trade attribute) on primary
  skill-inheritance slots. Fixed the Bound icon not displaying when a Bound
  Skill Book and a tradable Skill Book were inherited together.
- **Skill Macro:** Improved the wording of the pop-up shown when trying to
  set a hotkey already in use as a macro hotkey.

## Known Issue (carried in this notice)

- **Seal:** A scroll bar displays in the Seal Combination window, depending
  on screen resolution. *(Fixed later the same day — see
  [2026-09-09-neoupdate-additional-update.md](2026-09-09-neoupdate-additional-update.md).)*

## Neo Servers (Jin, Lyn)

**Soul Pass**
- **Leap Special Pass** (after 9/9 maint. – before 10/7 maint.): Started a
  new Soul Pass, the "Leap Special Pass." Complete missions within the Soul
  Pass to earn rewards. Activating Leap Special Pass Plus rewards doesn't
  apply the Soul Pass Plus convenience features.

**Events**
- **Comeback Style Costume Box** (after 9/9 maint. – before 10/7 maint.):
  Added 13 event transmute recipes.
- **Event Ended — "Martial Butterfly Costume Box":** Deprecated 1 event item.
  Removed the item exchangeable for the "Jewel Voucher" from the Dragon
  Express.

## Specialization Server (Gold)

**Soul Pass**
- **Specialization Leap Special Pass** (after 9/9 maint. – before 9/30
  maint.): Started a new Soul Pass, the "Specialization Leap Special Pass."
  Complete missions within the Soul Pass to earn rewards.

**Events**
- **Autumn Fortune Box** (after 9/9 maint. – before 10/7 maint.): Added 18
  items exchangeable for "Autumn Coin" to the Dragon Express. Added 7 event
  transmute recipes.

**System**
- **Boost Mission:** Added a guidance pop-up, shown when refining, to help
  evenly grow the enhancement stage of Winterbane and White Light
  accessories during the Boost Mission. Fixed the Hongmoon Blessing reset
  guidance message to display when a Boost Mission EXP reward would level
  the character up to 45 or above. Removed the "Claim All Rewards" button.
  Added a guidance message, shown when refining, to help evenly grow the
  enhancement stage of Winterbane and White Light accessories during the
  Boost Mission.

Thank you.
