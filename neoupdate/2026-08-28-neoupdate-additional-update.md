Greetings, Daehyeop.

We thank all our customers who love Blade & Soul NEO, and would like to announce
the details of the additional update carried out on August 28.

### System

**System > Server Transfer**
- Changed so the target server is left unselected when transferring from the
  Boost Server.

**System > Character Creation**
- Added Boost Server guidance to the character-creation flow on the
  Neo/Specialization servers.

### Interface

**Interface > Server Select**
- New/returning accounts now see the server-select window on login.

**Interface > Character Lobby**
- Added Boost Server guidance text to the character lobby on the
  Neo/Specialization servers.

Thank you.
