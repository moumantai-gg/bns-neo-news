# BNS Neo News

Event and update notes for Blade & Soul Neo — informal community tracking, not official
announcements.

## What goes here

Dated write-ups on server events, patches, and updates. Filed flat at the repo root, named:

```
YYYY-MM-DD-short-slug.md
```

GitHub's file listing sorts by name, so this keeps everything chronological without needing
subfolders. If this grows large enough that the root listing gets unwieldy, we'll split into
year folders or categories (e.g. `events/`, `patch-notes/`) at that point.

## Scope

This repo is for shareable event/update notes only. Class analysis, economy/probability
research, and terminology glossaries are kept in a separate private repo.
